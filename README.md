# ByteSpace

A responsive course marketplace frontend built with Next.js.

## Run Locally

Requirements: Node.js 20 or newer and npm.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm run start
```

## Checks

```bash
npm run lint
npm run typecheck
```

## Built With

- Next.js 16 and React 19
- TypeScript
- Tailwind CSS 4
- GSAP for interface animations
- Lucide React and React Icons
